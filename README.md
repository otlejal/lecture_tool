# Лекционный помощник

![Python](https://img.shields.io/badge/python-3.10%2B-blue)
![FastAPI](https://img.shields.io/badge/FastAPI-0.115%2B-009688)
![Whisper](https://img.shields.io/badge/faster--whisper-1.0%2B-6f42c1)

Локальное веб-приложение для преподавателя: записываете лекцию → получаете расшифровку → конспект, презентацию и тест. Работает как с локальной моделью Whisper (CPU или CUDA), так и с удалённым OpenAI-совместимым сервером распознавания; для генерации текста подойдёт любой OpenAI-совместимый LLM API (Ollama, LM Studio, llama.cpp, vLLM, облачные провайдеры).

## Возможности

- 🎙 **Запись и загрузка.** Запись с микрофона прямо в браузере (аудио уходит на сервер кусками по мере записи) или загрузка готового файла: `webm`, `mp3`, `wav`, `m4a` и другие форматы.
- 📝 **Распознавание речи.** Локальный [faster-whisper](https://github.com/SYSTRAN/faster-whisper) с батчингом и VAD-фильтром либо удалённый сервер с эндпоинтом `/audio/transcriptions`.
- 🧾 **Конспект.** Краткий или полный, с терминами, примерами и учётом пожеланий преподавателя. Длинные лекции автоматически делятся на части (map-reduce), чтобы не упираться в лимит контекста.
- 📊 **Презентация.** Модель возвращает не HTML, а структуру слайдов (JSON): заголовки, тезисы, цифры, цитаты, сравнения, код. Готовую колоду с навигацией и анимацией собирает проверенный HTML-шаблон — 5 тем оформления и 8 раскладок слайдов.
- ✅ **Тест.** От 1 до 50 вопросов трёх типов (один ответ, несколько ответов, верно/неверно), три уровня сложности, пояснение к каждому ответу.
- 🎛 **Мастер-промпты.** Свои шаблоны промптов для конспекта, презентации и теста с предпросмотром итогового запроса.
- 🎨 **Свои HTML-шаблоны.** Оформление результата можно заменить, не трогая код.
- 🗂 **Каталог лекций.** Папки `Группа / Предмет / Дата` на диске, статусы этапов, удаление, миграция старых лекций.
- ⚙️ **Настройки в интерфейсе.** Автосохранение, проверка подключения к LLM и список доступных моделей, управление скачанными моделями Whisper (диск и память).
- 📤 **Экспорт.** Скачивание готовых файлов: `transcript.txt`, `summary.html/json`, `slides.html/json`, `quiz.html/json`.
- 🧪 **Тесты.** Покрытие ключевой логики через `pytest`.

## Как это работает

```text
Микрофон / файл
      │
      ▼
Распознавание речи (faster-whisper локально или удалённый сервер)
      │  transcript.txt
      ▼
LLM (OpenAI-совместимый API)
      ├── конспект      → summary.json → summary.html
      ├── презентация   → slides.json  → slides.html
      └── тест          → quiz.json    → quiz.html
```

Все длительные операции (распознавание, генерация) выполняются фоновыми задачами: интерфейс показывает прогресс и не блокируется.

## Быстрый старт

### Windows: одним кликом

Запустите `start.bat` — скрипт сам создаст виртуальное окружение `.venv`, установит зависимости и откроет приложение в браузере.

### Вручную (Windows / Linux / macOS)

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt
copy config.example.yaml config.yaml   # Linux / macOS: cp
python run.py
```

Приложение поднимется на <http://127.0.0.1:8000> и откроется в браузере. Адрес и порт можно изменить переменными окружения `LECTURE_HOST` и `LECTURE_PORT`.

### Локальный Whisper на GPU (CUDA)

По умолчанию в настройках выбрано устройство `cuda`. Для CTranslate2 нужны библиотеки CUDA 12 — проще всего поставить их через pip:

```bash
.venv\Scripts\python.exe -m pip install -r requirements-cuda.txt
```

Если GPU нет, в разделе **Настройки → Распознавание речи** выберите устройство `cpu` и тип вычислений `int8`.

## Настройка

Все настройки хранятся в `config.yaml` (в репозиторий не попадает — в `.gitignore` лежит только образец `config.example.yaml`). Файл можно редактировать вручную или менять значения в интерфейсе — изменения сохраняются автоматически.

```yaml
language: ru
lectures_dir: lectures

transcription:
  backend: local            # local | remote
  local:
    model: medium           # tiny, base, small, medium, large-v3, large-v3-turbo, distil-*
    device: cpu             # cpu | cuda
    compute_type: int8      # int8 для CPU, float16 для GPU
    batch_size: 8           # > 1 включает батчинг (ускорение на GPU)
    vad_filter: true
  remote:
    base_url: http://localhost:8000/v1
    model: large-v3
    api_key: ''
    timeout: 3600

llm:
  backend: remote           # local | remote
  local:
    base_url: http://localhost:11434/v1
    api_key: ''
    model: qwen2.5:7b
    timeout: 900
  remote:
    base_url: https://example.com/v1
    api_key: ВСТАВЬТЕ_ВАШ_КЛЮЧ
    model: deepseek-flash
    timeout: 900
  temperature: 0.3
  max_chunk_chars: 20000    # размер части при разбиении длинного текста
```

### Требования к серверам

- **LLM:** эндпоинты `POST /chat/completions` и `GET /models` (OpenAI-совместимый API). Поддерживается `response_format: {"type": "json_object"}`; если сервер его не понимает, клиент автоматически повторяет запрос без него. Ответ модели проверяется по схеме, при ошибке модель просят исправить JSON.
- **Удалённый Whisper:** эндпоинт `POST /audio/transcriptions` с `response_format: verbose_json`. Если сервер не возвращает сегменты, используется общий текст.

Модели Whisper скачиваются автоматически при первом использовании в кэш HuggingFace. В разделе настроек видно, какие модели уже на диске и какие загружены в память; их можно выгрузить, не перезапуская приложение.

## Использование

1. **Запись и текст.** Создайте лекцию (группа, предмет, название), запишите звук с микрофона или загрузите файл, затем запустите распознавание. Текст расшифровки можно отредактировать вручную.
2. **Конспект.** Выберите источник (расшифровка или свой текст), длину, учитывать ли отступления, убирать ли слова-паразиты, добавлять ли примеры и свои пожелания. Результат можно пересобрать в другом шаблоне.
3. **Презентация.** Источник — конспект, расшифровка или свой текст. Настройте число слайдов (3–40), тему оформления (или «Авто»), аудиторию и дополнительные пожелания.
4. **Тест.** Источник — конспект, расшифровка или свой текст. Задайте количество вопросов, сложность и типы.

Результаты каждого этапа сохраняются в папке лекции и доступны для скачивания.

### Структура хранения

```text
lectures/
└── ИТ-101/                    # группа
    └── Базы данных/           # предмет
        └── 2026-02-14_10-30-00/
            ├── meta.json      # название, группа, предмет, дата
            ├── audio.webm     # исходная запись или загруженный файл
            ├── transcript.txt
            ├── summary.json
            ├── summary.html
            ├── slides.json
            ├── slides.html
            ├── quiz.json
            └── quiz.html
```

## Шаблоны и мастер-промпты

- **HTML-шаблоны** лежат в `templates/` (`summary_default.html`, `slides_default.html`, `quiz_default.html`). В месте метки `{{DATA}}` вставляется JSON с результатом; вся вёрстка и логика показа остаются в шаблоне. Свои шаблоны сохраняются в `templates/user/` и появляются в выпадающем списке интерфейса.
- **Мастер-промпты** хранятся в `prompts.json` (тоже в `.gitignore`). В шаблоне обязательна метка `{{TEXT}}` — текст источника, `{{RULES}}` — блок правил, собранный из настроек блока. Перед сохранением можно посмотреть, как будет выглядеть итоговый промпт.

## HTTP API

Интерфейс общается с бэкендом по REST, всё под префиксом `/api`:

| Метод | Путь | Назначение |
|---|---|---|
| `GET/PUT` | `/api/settings` | чтение и сохранение настроек |
| `POST` | `/api/llm/check` | проверка LLM-сервера и список моделей |
| `GET` | `/api/whisper/status` | скачанные и загруженные модели Whisper |
| `POST` | `/api/whisper/unload` | выгрузка модели из памяти |
| `GET/POST/DELETE` | `/api/lectures[...]` | каталог лекций |
| `POST` | `/api/lectures/{id}/audio[/chunk]` | загрузка файла или кусков записи |
| `POST` | `/api/lectures/{id}/transcribe` | запуск распознавания (фоновая задача) |
| `GET/PUT` | `/api/lectures/{id}/transcript` | чтение и правка расшифровки |
| `POST` | `/api/lectures/{id}/summary` · `/slides` · `/quiz` | генерация (фоновая задача) |
| `POST` | `/api/.../render` | пересборка HTML в другом шаблоне |
| `GET` | `/api/jobs/{job_id}` | статус и прогресс задачи |
| `GET` | `/api/lectures/{id}/files/{name}` | скачивание готовых файлов |
| `GET/POST/PUT/DELETE` | `/api/prompts[...]` | мастер-промпты |
| `GET/POST` | `/api/templates/{kind}` | HTML-шаблоны |

## Тесты

```bash
.venv\Scripts\python.exe -m pytest      # Windows
# или: python -m pytest
```

Тесты не обращаются к реальным сетям и моделям: LLM и Whisper подменяются заглушками.

## Структура проекта

```text
app/
  main.py         FastAPI-приложение и раздача статики
  api.py          REST API, фоновые задачи
  config.py       модель настроек и config.yaml
  storage.py      каталог лекций на диске
  transcriber.py  локальный и удалённый Whisper, декодирование аудио
  llm.py          клиент OpenAI-совместимого API, разбор JSON
  summarizer.py   конспект и разбиение длинного текста
  slides.py       структура презентации и правила вёрстки
  quiz.py         генерация и проверка тестов
  render.py       сборка HTML из шаблона
  prompts.py      мастер-промпты

```

## Примечания

- Приложение рассчитано на локальный однопользовательский запуск и не имеет аутентификации. Не выставляйте его в интернет без дополнительной защиты.
- `config.yaml` может содержать API-ключи — он исключён из git. Не коммитьте его и не пересылайте вместе с папкой проекта.
- Аудио декодируется через PyAV, поэтому отдельная установка FFmpeg не требуется.
- Одновременно в памяти держится только одна модель Whisper: при смене модели предыдущая выгружается.
